# Travel Memory｜旅途手帳

## 專案定位

Travel Memory 是一個以「旅行前、旅行中、旅行後」為完整生命週期設計的個人旅遊管理平台。

系統希望讓使用者不只規劃下一趟旅行，也能長期保存自己的旅行足跡、照片、日記與回憶。

產品核心不是單純的行程規劃工具，而是：

> 規劃未來的旅行、記錄正在發生的旅行、收藏過去的旅行。

## 核心概念

### 過去 Past
- 世界旅行足跡
- 去過的國家與城市
- 歷史旅行紀錄
- 旅行照片
- 旅行日記
- 心情紀錄
- 旅遊統計

### 現在 Present
- 查看目前旅行
- 當日行程
- 新增照片
- 新增日記
- 紀錄地點與心情

### 未來 Future
- 建立下一趟旅行
- 出發日期
- 行程規劃
- 景點規劃
- 備忘事項
- 出發倒數
- 旅行準備進度

## 產品特色

### 1. 世界地圖足跡
以世界地圖作為主要視覺元素，讓使用者查看去過的國家與城市、造訪次數，以及對應的旅行、照片與日記。

### 2. 旅行回憶管理
每趟旅行可以保存日期、國家、城市、景點、照片、日記、心情與行程。

### 3. 未來旅行規劃
使用者可以提前建立未來旅行，包含出發與回程日期、每日行程、景點、住宿、交通、備忘與準備事項。

### 4. 出發倒數
首頁可突出顯示下一趟旅行、出發日期與剩餘天數，讓「期待旅行」成為產品體驗的一部分。

### 5. 智慧照片整理
Travel Memory 可利用照片 EXIF、拍攝日期、GPS、地點資訊與 AI 圖像辨識協助整理大量旅遊照片。

AI 的用途是協助分類、辨識與搜尋，而不是大量生成內容。

## 專案原則

開發優先順序：

1. 功能正確
2. 操作好用
3. 介面完整
4. 異常可處理
5. 資料可靠
6. 權限安全
7. 系統可維護
8. 最後才考慮額外功能

## 專題期間

- 大三上：基礎系統與 MVP
- 大三下：完整產品化、智慧功能、安全與品質提升

由於大三上課業較忙，因此三上進度安排較輕，三下為主要完整化階段。
