# Travel Memory Features

## A. 世界地圖
- 世界地圖展示
- 標示已造訪國家
- 標示已造訪城市
- 點擊國家查看旅行
- 查看造訪次數
- 查看相關照片
- 查看相關日記

未來可擴充：
- 足跡完成比例
- 國家統計
- 城市統計
- 不同年份足跡
- 地圖篩選

## B. 旅行管理
每趟旅行應具有：
- 旅行名稱
- 國家
- 城市
- 開始日期
- 結束日期
- 封面
- 行程
- 照片
- 日記
- 心情
- 備忘

使用者可以：
- 建立旅行
- 修改旅行
- 查看旅行
- 刪除旅行

## C. 照片管理
基本功能：
- 上傳照片
- 多張照片上傳
- 查看照片
- 刪除照片
- 依旅行分類
- 依日期分類
- 依地點分類

自動化整理可讀取：
- EXIF DateTime
- GPS Latitude
- GPS Longitude

並利用 GPS 取得：
- 國家
- 城市
- 地區

## D. AI 圖像識別
AI 定位為「智慧整理工具」。

可能用途：
- 美食、建築、城市、自然景觀、海灘、夜景、人物、博物館等圖片類型識別
- 知名景點與地標辨識
- 語意搜尋
- 相似照片與重複照片偵測

AI 的目標是降低照片整理成本，而不是替使用者製造旅行內容。

## E. 旅行日記
每篇日記可包含：
- 日期
- 地點
- 文字內容
- 心情
- 照片

## F. 未來旅行
可包含：
- Destination
- Departure Date
- Return Date
- Daily Itinerary
- Attraction
- Accommodation
- Transportation
- Notes

## G. 出發倒數
首頁顯示下一趟旅行的：
- 目的地
- 出發日期
- 剩餘天數

## H. 旅行準備度
Checklist 可包含：
- 機票
- 飯店
- 網卡
- 保險
- 行李
- 行程
- 交通

並計算旅行準備度百分比。

## I. 個人旅行統計
例如：
- 去過國家數
- 去過城市數
- 旅行次數
- 旅行總天數
- 照片總數
- 最常去國家
- 最常去城市

## J. 帳號系統
後期完整版本需要：
- 註冊
- 登入
- 登出
- 修改個人資料
- 修改密碼
- 忘記密碼

每個使用者的資料必須完全隔離。
