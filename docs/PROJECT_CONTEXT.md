## 當前狀態

- Phase 1–3 核心完成。旅行、足跡、相簿、日記與心情皆已實作。國家層級的到訪摘要與關聯內容入口、日記與單張照片或地點的直接關聯仍待補。
- Phase 4 主要功能已上線。每日多站、景點搜尋、倒數、準備清單、站間交通註記可用。即時路線查詢需 Google Routes API 金鑰與實際驗證。
- Phase 5 可讀取 EXIF 日期與 GPS，並建議鄰近城市。全球地區反查、AI 辨識、語意搜尋與相似照片偵測仍待做。
- Phase 6–8 已有基本 UI 狀態、搜尋與篩選、私人登入與歸屬檢查。待補忘記密碼、完整備份還原、相簿縮圖與分頁、送出重試，以及手機與異常情境驗證。正式版目前採單一擁有者。
- Phase 9 已部署正式站，東京示範可用。已有[專題報告](專題報告.md)、[展示流程](展示流程.md)與[口試說明](口試說明.md)初稿，應依最新功能更新並核對最終簡報和圖表。

後續順序：帳號復原與資料還原 → 照片分類 → 國家足跡總覽 → 發表材料更新。技術與部署細節另見[實作狀態](../IMPLEMENTATION_STATUS.md)及[更新紀錄](../CHANGELOG.md)。
